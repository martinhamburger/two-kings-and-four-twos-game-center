# 固定局数友谊赛

## 玩家流程

普通三人斗地主、欢乐三打一、麻将、德州建房时选择自由对局或 1、4、8、12 局。自由对局是默认值，旧房间不改变。技能斗地主继续使用原来的胜利点赛制。

第一局实际发牌后固定名单，不能换人或替换人机。局间仍需准备；只统计成功结算的唯一对局。无人叫地主重发不计局；麻将流局、连庄后的新一局和德州弃牌结算都计局。中止退款不计局。

普通斗地主累计积分，麻将、德州累计净筹码变化；补筹码不算盈利。最高成绩相同则并列冠军。打满后服务端拒绝继续开局、原子释放占座，最后的牌局和战报保留。主动提前结束或名单无法维持时保留已结算成绩，不颁冠军。

牌桌上的“本场成绩 / 本场结算”可随时打开和关闭。首次完成时短暂播放现有国王、公主素材，减少动态效果或关闭牌桌特效时使用静态王冠。刷新和轮询不重复颁奖。整桌战报中的“查看牌桌”可返回原桌查看最后结果。

## 拒绝请求流修复与完整验收

之前完整冒烟在未登录/跨站请求被拒绝后超时，Linux CI也有相同现象。现将头像接口原有的未读正文清理函数复用至反馈接口的 `finally`：返回拒绝结果前流式丢弃剩余正文，不保留数据、不重试写请求；恢复先认证再解析正文的原有顺序。原有来源检查、权限及配额断言全部保留。

复测跨站POST返回403后，下一请求立即返回200且额度不变；读取及不读取拒绝响应正文两种客户端行为均通过。最终 `npm run test:smoke` 完整通过768项检查，包括新增友谊赛专项与原头像、反馈、权限、并发、记录和游戏用例。日志 `work/pr25-smoke.log`、`work/smoke-local.json`；全量源码检查 `work/pr25-check.log`，构建 `work/pr25-build.log`，此次修改文件定向ESLint退出0。

GitHub CI仍是独立的最终门槛，最终结果见PR25检查。物理手机触摸、Safari和线上延迟未实测；本轮手机证据来自Edge浏览器设备尺寸模拟。用户决定合并，合并不会自动上线。
