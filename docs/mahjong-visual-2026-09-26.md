# 麻将青绿牌桌：实现与验收

本次只改变展示层。青绿绒面、深色桌框、细金边、牌体侧面和高光全部由 CSS 绘制，继续复用现有 SVG 牌面；没有增加 3D 引擎、图片下载、数据库变更或规则版本。

## 布局与可见范围

- 宽屏接近 16:9，在手牌与操作区最低高度不足时允许略高；中等窗口减弱透视，手机取消透视并将手牌分两行。
- 本人手牌、文字、头像和按钮保持正向。四家公共区域环绕余牌计数，吃碰杠靠近座位；长弃牌在固定区域内滚动，也可通过「完整牌桌」展开。
- 对手暗手仅按可见快照的 `count` 画牌背；暗杠仍遵循原来的隐藏规则，结算和下一局复用原有可见性逻辑。
- 清理通用主题中旧的固定布局规则，避免窄屏侧边头像区保留旧的 110px 高度。桌框、公共牌区、操作区和手牌槽使用单一套响应式尺寸。

## 正式构建点击与布局测量

测试使用本机独立数据库、四个本地账号及正式构建，通过浏览器实际操作。大量弃牌和多组副露为边界布局夹具，不作为规则正确性的证据。流局状态由现有引擎逐次超时产生，再实际点击准备下一局；另用可胡牌夹具点通选方案、确认、两张奖牌和胡牌结算。

20 个尺寸与状态组合均无页面横向溢出，手牌全部落在预留区域。各尺寸下牌桌、座位、操作栏和手牌槽的位置与尺寸不随上述状态变化。最后在固定 1440px 窗口复核 4/13/14 张手牌与 18 张弃牌，所有槽的坐标与尺寸差异为 0 CSS px。

实际点击通过：选牌及出牌、键盘滚动公开牌、完整牌桌、文字聊天发送与回执、牌桌详情、离桌确认并取消、胡牌方案选择与确认、逐张翻奖、查看结算、准备下一局。结算时三名对手均公开手牌，下一局显示三个牌背区域，不残留上局亮牌。另检查了 320px 等待开局提示和准备按钮。
