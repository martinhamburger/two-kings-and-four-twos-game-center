# 回放与精彩 TV：交付说明

## 2026-10-22 改进

- 德州开局、弃牌与全下后的回放正确标记下一位行动者或发牌阶段；过街保留下注结果与发公共牌两个独立步骤。
- 麻将打出牌、声明补杠后先更新响应状态再保存；完成杠后不残留等待响应或摸牌标记。声明、完成杠、杠后补牌仍分别记录。
- 进度条按牌局步数跳转，左右方向键每次一整步，Home / End 到首步 / 末步；聊天和表情仍按顺序播放，也可从记录单独跳转。末步后的消息继续播放完再结束。
- 打开逐步记录直接定位并聚焦当前条目，表情记录显示具体名称。切后台自动暂停，回前台需主动播放，避免错过牌局；弹窗和输入控件保留自己的键盘操作。

这些快照修复对新采集的对局生效，不追写历史存档，也不由文字日志猜造缺失动作。

本轮验证：`npm run check` 377 项通过；最后的针对回归 12 项通过；最终 typecheck、定向 ESLint、正式 build 和文档链接检查通过；`npm run test:smoke` 622 项检查通过。Edge 正式产物 14 个场景全部通过、无运行异常，包括三游戏各 320×568、390×844、844×390、1440×900 的进度、弹窗暂停、当前记录可达与页面无横向溢出，以及真实标签切换暂停。牌面图片加载后重新截图并人工查看窄屏和桌面。

浏览器使用已有独立本地存档检查展示与交互；密集聊天及末步之后的消息用本地存档快照配合合成消息响应验证，不冒充自然对局。新捕获状态由引擎回归检查，接口授权与原子提交由隔离库冒烟检查。实体手机触摸与生产负载未测。原生回车测试在补齐 CDP 的字符事件后复验通过，早期脚本失败不计作通过。

## 既有能力

- 观看以原牌桌为主体：投稿者在下方，其余玩家在原座位明牌，保留当局昵称、公共牌、出牌结果及聊天表情。约一秒自动开始，聊天依次播放。
- 播放控制独立占位。信息与投稿收进「这一局」，推荐语在牌桌外显示；逐步记录按需打开。终局留在牌桌，支持再看一遍，麻将结算主动查看。
- 个人回放、精彩 TV 与错误状态按账号和请求绑定；过期请求不覆盖新页面。TV 保留筛选和分页，私人记录保持本人视角，公开 TV 使用投稿者视角。
- 条件撤稿/下架保留管理员墓碑；技能版补齐操作完成后的真实快照。构建核对实际客户端资源，消除不存在的辅助预加载，并拒绝真实入口或依赖缺失。
