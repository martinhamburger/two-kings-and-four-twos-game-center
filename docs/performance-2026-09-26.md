# 斗地主合并同步：本地测量记录

2026-09-26，基线为 main `8e3eade`。使用正式 Worker 构建、独立本地数据库与三个临时真人账号；一个浏览器实际购买、处理装备、连续选牌、划选和出牌。其余账号由本地接口控制。没有使用线上账号或测量线上网络。

| 指标 | 改前 | 改后 |
|---|---:|---:|
| 60 秒窗口内的牌局/聊天周期 GET | 99（40 + 59） | 59（合并查询） |
| 同一窗口的周期查询传输量，含浏览器计入的响应开销 | 155,689 B | 25,890 B |
| 静止牌局页面渲染 | 171 秒内 965 次，约 339 次/分钟 | 商店静止 50 秒内 0 次 |
| 指针输入到第二个动画帧的 p95 | 38.2 ms，30 个样本 | 30.3 ms，29 个样本 |
| 样本内超过 50 ms 的长任务 | 0 | 0 |

周期查询数量减少约 40%，传输量减少约 83%。改后窗口中有一次购买 POST，单独统计且没有随后的重复完整 GET；该 POST 本机响应为 6.8 ms。首次入房完整查询、操作 POST、好友心跳和动画资源不纳入周期查询统计。

帧指标是输入后的双 `requestAnimationFrame` 采样，包含显示帧等待，不是 INP，也不是服务器确认时间。素材首次进入与缓存后均可操作，本次环境未复现明显掉帧，不能据此宣称已覆盖所有线上卡顿。影子牌、复制装备和 21 张手牌的连续选择与实际划选/出牌已点击通过。

计数探针只用于本地测量，已从提交移除。时间、请求和交互原始记录及截图在忽略的 `work/performance/` 中，不包含在发布产物或 PR 文件里。正式代码不增加遥测上报。

## 回归覆盖

- 虚拟时钟验证活跃每分钟最多 60 次、等待/局间最多 20 次，隐藏暂停、返回立即同步；慢读串行、超时退避、取消后晚到响应失效。
- 接口验收包括已知版本的权限检查、无变化小包、本人私有视图、聊天独立游标、同版本两人购买只成功一次、失败者金币不变、机器人推进和一整局真人 v3。
- 实际浏览器验证购买立即更新、装备开窗/选牌/发动、倒计时继续走、连续选牌、鼠标划选、出牌与聊天发送。经典斗地主、麻将、德州接口仍包含在默认冒烟测试中。
