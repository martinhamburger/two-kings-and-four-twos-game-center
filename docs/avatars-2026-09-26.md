# 全站头像与组合验收记录

2026-09-26。头像分支基于四向麻将牌桌，独立审阅；没有发布、合并或连接线上数据库。

## 实现

大厅个人资料和本人牌桌头像可进入编辑。静态 JPG / PNG / WebP 在解码前限制 10MB、2400 万像素；浏览器按照片方向解码，支持拖动、缩放和键盘调整位置。透明像素铺米白底。保存时只上传 256×256、64KB 以内的 JPEG，服务端再次检查格式、尺寸、长度并移除 APP/COM 元数据。

`user_avatars` 单独存储图片、递增版本和更新时间；恢复默认保留版本墓碑。写接口以登录用户为目标，要求同源和预期版本，用单条原子语句写入。冲突、错误或超时保留裁剪，超时读取当前资料核实，不自动重试写入。图片读取要求登录，并使用私有版本地址缓存。

好友心跳一并返回本人、好友及当前真实同桌玩家的头像元数据，不返回图片二进制。入桌仅额外刷新一次现有好友查询，平时沿用 30 秒周期；没有头像专用轮询，也没有在每秒牌局同步中查询头像。头像采用按用户订阅的独立状态，同版本心跳保留对象引用。切账号更换状态容器，图片失败回退剪影。

存储使用既有 D1 BLOB，不新增存储桶；依据 [D1 类型转换文档](https://developers.cloudflare.com/d1/worker-api/#type-conversion)。新增迁移为 `0006_fast_pestilence.sql`，仅在隔离本地库执行。

## 验证

- `npm run check`：270 项通过，含图片结构、尺寸、动画拒绝、元数据移除、裁剪边界及迟到版本测试。
- `npm run build`：通过。
- `npm run test:smoke`：最终独立头像分支 371 项通过。覆盖头像身份与同源校验、格式及体积拒绝、图片访问、并发更新仅一项成功、旧版本恢复拒绝、默认版本递增、他人账号隔离、好友元数据，以及头像不改变房间版本。
- 正式产物实际点击：大厅与麻将头像入口、PNG 保存立即展示、拖动、键盘缩放/位移、JPG 方向校正、WebP、更换/取消、恢复默认、损坏文件、SVG、10MB 和 2400 万像素限制、并发冲突后保留裁剪并手动成功重试。
- 本地故障代理用于上传失败及“服务器已保存但回执晚到”场景，不修改正式业务代码。
- 手机裁剪截图检查 320×700，弹窗和保存按钮均在屏内；桌面检查 1440×900。

自动接口通过和实际点击分别记录，不能相互替代。三分支集成测量结果在下方组合验收段记录；不将本地帧反馈称为线上 INP。

## 三分支集成测量

本地组合性能 PR #12、麻将 PR #13 和头像改动，三个真人账号保留独立会话。集成时保留统一同步、缓存座位组件和头像订阅；`app/page.tsx` 的共同修改已在本地组合分支解决。此记录不代表远程 PR 已合并。

| 测量 | 原基线 | 三项组合后 |
|---|---:|---:|
| 活跃 60 秒内牌局/聊天周期查询 | 99 次 | 60 次，全部为统一同步 |
| 活跃窗口周期响应传输量 | 155,689 B | 26,364 B |
| 等待 60 秒周期查询 | — | 20 次，无独立聊天查询 |
| 好友心跳 | 原周期 30 秒 | 活跃、等待均 2 次/分钟 |
| 本地指针到第二帧 p95 | 38.2ms / 30 样本 | 29.5ms / 34 样本 |
| 大于 50ms 长任务 | 0 | 0 |

- 活跃静止观察 84 秒，页面、商店和对手座位均零次重复渲染。等待观察 138 秒也均为零；期间实际打开头像编辑并保存透明 PNG，只有头像组件更新。
- 实际购买小炸弹、完成购买、选 K 使用搞四张（17→21 张）、连续选/取消 30 次、划选 5 张、重选并打出一张（21→20 张）。购买客户端资源响应为 9.3ms；本地 Worker 对购买、完成购买、装备确认、出牌的处理记录分别为 9/4/8/14ms。这些不是线上网络延迟。
- 头像元数据和图片单独统计。等待测量窗口里的 5 次头像相关访问来自编辑/保存/图片载入及验证读取，没有头像周期轮询。入房与恢复同步不算周期查询。
- 网络活跃样本来自浏览器资源记录；等待样本来自同一预览服务的 60,004ms 请求日志窗口（只有本测试浏览器在该服务轮询）。浏览器默认资源记录容量已满，因此没有用不完整资源记录推算等待次数。
- 帧反馈使用临时双 `requestAnimationFrame` 探针，并非 INP。探针只存在于本地测量产物，提交和最终构建均移除。数据来自本机，不能声称覆盖所有线上卡顿。
- 自动检查与实际交互分别完成。共用头像已实际出现在三游戏大厅、麻将/斗地主/德州本人座位及好友列表；换账号不串图。好友头像由下一次心跳自动显示。透明 PNG 最终保存为 3,961 B、256×256 JPEG，无 alpha、EXIF 或 ICC，角落为铺底米白色。

本次测量还发现并修复了入桌刷新 hook 订阅整个好友状态导致的每 30 秒整桌重绘。刷新函数改用独立稳定上下文；无变化心跳以及头像保存均不再重画斗地主整桌。

麻将在同一集成产物中复测，83 秒静止观察期间倒计时持续变化，页面与牌桌主体均零次重复渲染。额外实际点击通过菜单邀请复制、牌桌详情、同桌好友、房主结束整桌、返回大厅导航恢复，以及德州头像编辑和离桌。

最终组合产物已移除所有探针：`npm run check` 276 项通过，`npm run build` 通过，`npm run test:smoke` 392 项通过。静态布局与正式点击验收沿用上文分别列出的证据，不将自动检查数量视为人工点击覆盖数。

最终拒绝路径会以不保留内容的方式读完上传请求流，包含未登录、错误来源、格式及大小拒绝；避免本地 Workers 代理复用未完成的上传连接。独立头像分支最终复跑为 270 项检查、正式构建通过、371 项冒烟通过。冒烟数量随随机牌局推进次数变化。
