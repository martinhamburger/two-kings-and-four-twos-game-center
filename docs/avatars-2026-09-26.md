# 全站头像与组合验收记录

2026-09-26。头像分支基于四向麻将牌桌，独立审阅；没有发布、合并或连接线上数据库。

## 实现

大厅个人资料和本人牌桌头像可进入编辑。静态 JPG / PNG / WebP 在解码前限制 10MB、2400 万像素；浏览器按照片方向解码，支持拖动、缩放和键盘调整位置。透明像素铺米白底。保存时只上传 256×256、64KB 以内的 JPEG，服务端再次检查格式、尺寸、长度并移除 APP/COM 元数据。

`user_avatars` 单独存储图片、递增版本和更新时间；恢复默认保留版本墓碑。写接口以登录用户为目标，要求同源和预期版本，用单条原子语句写入。冲突、错误或超时保留裁剪，超时读取当前资料核实，不自动重试写入。图片读取要求登录，并使用私有版本地址缓存。

好友心跳一并返回本人、好友及当前真实同桌玩家的头像元数据，不返回图片二进制。入桌仅额外刷新一次现有好友查询，平时沿用 30 秒周期；没有头像专用轮询，也没有在每秒牌局同步中查询头像。头像采用按用户订阅的独立状态，同版本心跳保留对象引用。切账号更换状态容器，图片失败回退剪影。

存储使用既有 D1 BLOB，不新增存储桶；依据 [D1 类型转换文档](https://developers.cloudflare.com/d1/worker-api/#type-conversion)。新增迁移为 `0006_fast_pestilence.sql`，仅在隔离本地库执行。

## 验证

- `npm run check`：270 项通过，含图片结构、尺寸、动画拒绝、元数据移除、裁剪边界及迟到版本测试。
- `npm run build`：通过。
- `npm run test:smoke`：379 项通过。覆盖头像身份与同源校验、格式及体积拒绝、图片访问、并发更新仅一项成功、旧版本恢复拒绝、默认版本递增、他人账号隔离、好友元数据，以及头像不改变房间版本。
- 正式产物实际点击：大厅与麻将头像入口、PNG 保存立即展示、拖动、键盘缩放/位移、JPG 方向校正、WebP、更换/取消、恢复默认、损坏文件、SVG、10MB 和 2400 万像素限制、并发冲突后保留裁剪并手动成功重试。
- 本地故障代理用于上传失败及“服务器已保存但回执晚到”场景，不修改正式业务代码。
- 手机裁剪截图检查 320×700，弹窗和保存按钮均在屏内；桌面检查 1440×900。

自动接口通过和实际点击分别记录，不能相互替代。三分支集成测量结果在后续组合验收段记录；不将本地帧反馈称为线上 INP。
