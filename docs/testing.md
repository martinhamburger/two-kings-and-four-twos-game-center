# 验收：怎样知道改动没有把牌桌弄坏

## 自动检查

```bash
npm run check
npm run build
npm run test:smoke
```

`check` 包含素材清单、TypeScript、现有规则测试、新增缓存/发布框架测试和文档链接检查。规则测试包括牌张守恒、麻将拆法和倍数、德州牌型分布/边池、机器人、导航、聊天和动画时序。

`test:smoke` 使用正式构建，自动创建独立本地数据库和测试账号，检查五个页面入口、三种人机房、成员权限、聊天幂等、表情冷却及聊天不改变牌局版本，以及德州等待预览、越权行动拒绝、加注后金额更新和重复提交冲突。它只接收本机地址，不接收线上 URL。结果在 `work/smoke-local.json`。

历史 `tests/*-api.test.ts`、`reset.test.ts`、`emotes-races.test.ts` 等是专题夹具测试，需要对应的 `work/` 本地夹具，有些会修改测试库。它们没有被冒充为默认 CI 已覆盖的项目；不要直接对线上执行，也不要把其中的固定测试密码当作真实凭据。需要深入修改该功能时，应先在隔离库准备相应夹具。

`npm run lint` 保留为辅助工具，旧代码还有风格问题；当前发布门槛使用上述已可运行的检查，不声称全仓 ESLint 已清零。

## 每次发布的人工点击

运行 `npm start`，打开 `http://localhost:8787/`：

本地验收服务器默认开启开发者模式：**人机测试 + 扩展 landlord-v3** 的新房间里，商店下方会出现「开发者装备测试」，可授予目录中的任意装备；`/dev/motion`、`/dev/emotes` 也可直接访问。开关在房间创建时写入房间状态，改动后需要新建人机房。要按纯正式产物口径验收时，先设置 `LOCAL_DEV_TOOLS=0`（PowerShell：`$env:LOCAL_DEV_TOOLS=0; npm start`）再启动；正式部署不会带上这个变量。

1. 从顶栏依次点斗地主、麻将、德州、对局记录，再前进/后退。应立即切换，输入和账号不串页。
2. 用测试账号进入人机房，实际选牌、出牌或下注。检查倒计时、筹码和操作按钮。首次进入扩展 landlord-v3 房间会弹出 4 页新手教程，看完（或跳过）后不再自动弹；工具栏「新手教程」可随时重看，牌桌上方会按阶段显示一行情境提示（商店/竞价/装备结算/出牌），教程里可关掉这些提示。
3. 发文字和表情，检查头像归属；打开图鉴重播表情及炸弹、飞机、胡牌动画。
4. 等缓存完成后刷新，检查仍显示完成。换图后只应更新变更素材。关闭动画、断网或图片失败不能卡住操作按钮。
5. 缩窄窗口或使用手机尺寸，检查自己的手牌、出牌按钮、聊天面板、麻将公开牌和德州多座位不遮挡。

按本次改动补充检查：改结算就打一局并看战报；改麻将方案就验选方案和翻奖；改导航必须在正式产物里实际点击。HTTP 200 不能替代交互验收。

## 新增测试

独立、不需要服务器的框架测试放 `tests/unit/*.test.ts`，`npm test` 自动包含它们。存量规则测试仍位于 `tests/` 并由 `package.json` 列出。新增接口检查可加入 `scripts/smoke-local.mjs`，保持独立本地数据库、不读取真实账号的原则。

缓存测试会构造比现有表情包更大的素材集合，检查自动下载预算、容量淘汰、跨页面复用、旧版本清理、并发去重、失败重试和配额不足。不能只测试现在恰好有多少张图。

## 德州预选与牌面专项

牌面和操作栏分别在 `components/holdem-card.tsx`、`components/holdem-controls.tsx`。德州不再使用斗地主的大花色样式。

- 用四位本地测试玩家开桌。别人的回合直接选中跟注，或选择加注并输入总额；此时牌桌下注和版本不变。让上一位加注，确认跟注数字更新、原加注输入不被提高。轮到本人，必须点击统一“确认”才付筹码。
- 预选过牌后发生下注，应取消过牌预选。换街、换手、切账号/房间、刷新、断线后恢复、页面回到前台均不恢复旧下注意图。
- 同一账户在另一个窗口行动后，本页也应清掉预选。旧版本提交只刷新局面，不能自动重试下注。
- 查看 4、6、10 人桌及手机、矮窗口尺寸，带下注金额/倒计时的座位也不能相互重叠。操作栏在牌桌下方独占空间，随页面滚动，不浮在座位上；等待摘要与本人行动区保留相同的基础高度。公共牌、底牌、摊牌与历史卡片共用德州组件；点数和花色分区，聊天/表情按钮独立放在操作栏右侧。

`tests/unit/holdem-preselection.test.ts` 检查这些边界的纯逻辑；真实按钮是否正确提交仍需要上述正式产物点击。

- 所有动作按钮只选择、不提交；确认只有轮到本人且选择有效时可用。新建德州房按前注整数倍下注，非法金额不能提交，旧 v1 房间保持兼容。

- 新 v3 德州前注 10 后跟到 30 只再付 20，剩余筹码从 990 变为 970；检查座位投入 30、跟注标签，换街后累计投入不清零。重复轮询不重复动画，减少动态效果和关闭特效保持静态。

### 简化加注与到时执行追加

新建 v4 房间验证跟注 60 后输入 70 或 61 均可加注；快捷填入跟注额与 +10/+50/+200 只改输入。到时方案登记不能改变筹码、行动者或期限，对其他玩家不可见；到期只执行一次。覆盖合法跟注/加注/全下、取消、过牌变付费、跟注上涨、旧手/街/本人行动后失效、冲突拒绝和无选择兜底。以本节替代此前“任何预选都不得自动提交”的验收要求；仍不得在到期前自动下注。


## 斗地主 v3 整合回归

- 新建经典与扩展房间分别验收；经典保留轻量牌桌、统一倒计时、紧凑聊天和牌桌详情。v3 的金币和装备只属于本桌，不改变账号积分。
- 在 v3 首局商店购买搞一张，确认完成购买后立即增加一张独立复制牌；公共日志只写复制数量，不暴露点数。完成购买后不能继续交易。升级按钮显示实际半价，跨级购买仍付原价且替换同系列旧装备。
- 多名玩家持有看底牌时各自只看到选择的那一张；商店期底牌完全隐藏。地主确定后底牌持续公开，进入装备窗口也不翻回牌背。
- 验证农民处理孤注、站起来跟他打后仍由地主首先出牌；跳过一个人的赌注装备不吞掉其他人的机会；借光结束后不跳过正常行动者。四带二转移按钮直接选择目标，不要求重选已经打出的手牌。
- 验证接龙顺子能被普通更大顺子压过，且每局只触发一次；重复牌实例、非法目标、过期房间版本均不能成交或出牌。
- 两件未实现装备不在可购买池。人脉每桌一次，清仓与同一持有者的人脉不能同局共同触发。
- v3 开局后固定三名玩家；局间离桌结束整桌并释放所有成员，不让后来者继承金币、装备或胜利点。整桌冠军战报可从斗地主筛选查看。
- 自动测试包含可重复随机种子的 12 桌完整赛制，以及真实本地接口的一整局 v3、权限拒绝、并发版本冲突和离桌清理。接口检查关闭开发者模式。页面点击结果另行记录，不能由这些自动测试代替。


## 统一大厅、好友与牌桌展示

- 三款大厅共用主卡片、加入房间表单、个人资料和好友栏，只改变主题色与游戏内容；斗地主介绍不混入麻将，顶部仍可切换游戏。桌面和手机检查加入表单无溢出。
- 用两位真人测试账号同桌：发送好友申请，接收方同意后才成为好友。检查重复申请、忽略、撤回、非同桌伪造请求和不能给人机加好友。退出登录后，好友不再显示在线。
- 好友离桌后，从右栏或「同桌好友」邀请；接收者点击「接受并入座」后进入正确游戏。邀请不能越过房满、已开局、人机单练和固定成员限制。邀请人离桌、过期或收件人不匹配时拒绝。
- 收到文字时角标固定在聊天按钮右上角，图标坐标不变。自己和他人的表情都只在牌桌播放，不进入聊天记录，也不增加文字未读数。
- 麻将桌面手牌 56×80，牌桌弃牌 30×41，结算手牌 33×47；中等窗口（581–1100px）手牌 44×63，手机保持自适应换行。对局中使用固定座位区、操作区和手牌区；多行弃牌、吃碰杠、倒计时和组合选择不得改变牌桌外框与手牌位置。公开牌过多时在座位区滚动，并可打开「完整牌桌」展开全部公开牌，不删除任何牌。结算时检查四家剩余手牌；准备下一局后再次隐藏对手手牌。德州旧房保留原摊牌可见范围，新 v5 房按下文全员亮牌验收。

`tests/unit/round-hands.test.ts` 覆盖结算公开与下一局隐藏；`tests/unit/social.test.ts` 和隔离数据库冒烟测试覆盖关系权限、心跳和三游戏邀请。页面点击单独验收，不能由这些自动检查替代。

- 麻将布局专项：在同一窗口分别检查空弃牌、每家 18 张弃牌、多组吃碰杠和 4/13/14 张手牌；记录牌桌、座位、操作栏和手牌的坐标与高度，切换状态应保持不变（允许浏览器亚像素误差）。检查 320px、390px、中等窗口和宽屏，所有手牌都留在手牌区内；操作组合浮层不推挤布局，完整牌桌可滚动查看，结算允许按手牌内容展开。


## 麻将青绿牌桌

- 视觉由 `app/mahjong/table.css` 管理；桌布和公开牌使用浅透视，头像、按钮、文字、本人手牌保持正向。不要在通用主题中再添加第二套固定行高。
- 在 1440、820、640、390、320px 下比较空弃牌、四家各 18 张弃牌、多组吃碰杠和 4/13/14 张手牌。牌桌内部的座位、操作栏和手牌槽坐标保持稳定，所有手牌留在槽内；选牌抬起后仍可点选。密集公开牌允许独立滚动，键盘聚焦后 End 可到末尾，「完整牌桌」能展开全部牌。
- 对手牌背数量取服务器可见的 `count`，不能以对手隐藏的 `hand` 重建牌面。结算亮牌后实际准备下一局，确认牌背恢复；再点通胡牌方案、两张奖牌、聊天、牌桌详情及离桌确认。
- 手机等待开局和胡牌选择的中央提示占满一行，文字不能被狭窄的余牌计数列挤压。倒计时预留自己的位置，不能盖在头像或牌背上。
- 本次正式构建的测量口径和结果见 [麻将视觉验收](mahjong-visual-2026-09-26.md)。

## 麻将离开房间

- 房间顶栏始终提供离开入口；普通玩家不能看到或调用结束整桌。未开局直接释放座位；开局后先回大厅按原超时时限托管，本局结算后原子释放成员记录，保留玩家身份、筹码、杠分和战报。选方案、翻奖期间也必须等完整结算。
- 大厅显示待离桌状态并定期推进牌局，刷新页面仍能恢复。已申请离桌的玩家不能手动出牌、改准备或在另一窗口绕过托管。
- 固定阵容不补人：有玩家正式退出后不再开始下一局，剩余房主可结束整桌。房主退出则转交仍在桌上的真人；最后一位真人退出后自动关闭空房。验证退出者可以加入新桌，旧桌重复请求不能释放新桌成员记录。

- 德州结算在每个座位旁显示服务端结算的最佳五张牌型（本人座位也显示）；旧房弃牌只标记「已弃牌」；新 v5 房全员展示已有公共牌可组成的牌型，弃牌身份另行标注，翻牌前弃牌获胜及中止另行说明。检查 4/10 人桌和窄屏，下一局开始清除上局牌型。

## 德州最低加注倍数与全员亮牌

- 新建 v5 房，前注 10、大盲 30，玩家加注至 90 后，下一位已投入 10 的玩家跟注额为 80，1 倍为最低加注幅度 60。点击 +1/+2/+5 分别在当前输入上增加 60/120/300；确认前不扣筹码，确认后按输入实际付出。对手再加注时更新倍数，保留原输入并重新校验，不能自动抬高已选金额。
- 不足额全下后的加注目标须向上取整到本桌下注单位；超出筹码不自动全下，未开放加注权仍不能提交。换街后最低下注幅度恢复，旧 v4 保留简化加注规则。
- 正常结算后每个座位亮两张底牌，包括弃牌者和其余玩家全弃后的赢家。已有公共牌不少于三张时计算现有牌面的最佳五张牌型；翻牌前结束只亮底牌，不补发公共牌。弃牌标记仍保留，弃牌者不能分池。战报也显示底牌。
- 实际点击到结算、打开本手详情，再准备下一局，确认底牌重新隐藏。旧 v1–v4 不扩大公开范围，中止不亮对手牌；验证 4/10 人桌和手机无牌张、牌型标签重叠。

- 麻将倒计时只放大数字与图标，不改胶囊框和预留状态区尺寸；检查 30/9/0 秒、桌面与手机均不遮挡头像和公开牌，外框不随计时跳动。

## 整屏四向麻将追加验收

本节替代上文麻将桌面尺寸与原顶栏位置要求。入桌隐藏站点顶栏，左上常驻菜单保留返回大厅、邀请、规则详情、声音与离桌入口；回大厅恢复导航。本人手牌在 1600×900 基准下为 80×114，固定左对齐；各家吃碰杠放在当地坐标的右侧。手机竖屏每行七张，始终保留两行高度。

- 依次检查 1920×1080、1440×900、820×900、640×720、844×390、390×844、320×700 和极矮 320×568；四向弃牌区域之间、弃牌与头像之间不得交叠。
- 检查 4/13/14 张手牌、每家至少 18 张弃牌和四组杠；所有手牌、公开组合留在各自区域，操作区和手牌起点不随张数变化。
- 查看旧弃牌后收到新牌，位置保持；回到最新和窗口旋转都正确处理滚动跟随。完整牌桌展开所有公开牌。
- 实际吃、碰、杠、选方案、翻奖、结算收起与准备下一局；结算亮牌不能在下一局继续显示。结算窗不能叠在尚未关闭的翻奖窗之上。
- 倒计时只刷新自身和依赖时限的小组件；同版本响应不替换整桌状态。不要将 DOM 坐标稳定当作渲染耗时或网络性能实测。

## 全站头像

实际点击三游戏大厅与本人座位头像，检查 PNG/JPG/WebP、方向校正、透明图、损坏/动画/超限文件、拖动/键盘缩放、取消、保存和恢复默认。失败及超时保留裁剪，旧版本冲突要求核实后手动保存。换账号后不能保留上一账号的图片资料。多人同桌与好友列表在既有心跳内更新，不增加每秒牌局查询。接口并发、授权与房间版本不变由默认隔离冒烟覆盖；截图和实测边界见 [头像验收](avatars-2026-09-26.md)。
